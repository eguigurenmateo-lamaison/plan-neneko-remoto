El método detrás del análisis

C.L.O.S.E.R. (Alex Hormozi)

Clarify · Label · Overview · Sell · Explain · Reinforce. Se compra por emoción y se justifica con lógica: primero se entiende y amplifica el dolor, después se presenta la solución. Máxima: "vende las vacaciones, no el vuelo".

Rapport N.S.F.G.A.

Name · Same · Fame · Gain/Pain · Aim. El esquema para romper el hielo con intención en los primeros minutos.
